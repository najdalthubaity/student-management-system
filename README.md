Student Management System

A desktop application developed using Java, JavaFX, and FXML to simplify student record management and academic administration.

Project Overview

The Student Management System provides a graphical interface for organizing student information, managing grades, and accessing academic reports. The project demonstrates the development of a multi-screen desktop application using JavaFX and the separation of user interfaces from application logic.

Key Features

* Login Interface: Dedicated login screen for accessing the application.
* Student Management: Interfaces for adding and viewing student records.
* Grade Management: Functionality for recording student grades.
* Academic Reports: A dedicated reporting interface for academic information.
* Desktop User Interface: Multiple FXML-based screens connected to Java controller classes.

Technologies Used

* Java 21 — Application logic and object-oriented programming
* JavaFX 21 — Desktop graphical user interface
* FXML — User interface layouts
* Maven — Dependency management and project configuration

Project Structure

* App.java — Application entry point and JavaFX initialization
* LoginController.java — Login screen controller
* HomeController.java — Home screen controller
* AddStudentController.java — Student registration functionality
* ViewStudentsController.java — Student records interface
* AddGradesController.java — Grade management functionality
* ReportController.java — Academic reporting interface
* src/main/resources/fxml/ — FXML interface files

Technical Skills Demonstrated

* Object-oriented programming with Java
* GUI development using JavaFX
* Event-driven programming
* FXML and controller integration
* Multi-screen application organization
* Maven project configuration
* Source code organization and version control with GitHub

Development Experience

This project provided practical experience in building a structured Java desktop application, connecting graphical interfaces with controller logic, and organizing a multi-file software project.
